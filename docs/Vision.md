# Vision

`ka` is a local knowledge and agent platform. It begins with reliable document
retrieval and grounded answers, then grows into knowledge extraction,
contradiction analysis, and agent-assisted workflows.

It is deliberately independent of a particular model vendor, inference runtime,
vector store, or tool protocol. Local providers are the default for private
documents. Hosted providers and tools may be configured when a workspace permits
them. Every answer and agent action must retain evidence and execution provenance.
